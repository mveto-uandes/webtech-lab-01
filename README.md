## Lab 2 — Interactive features

- **Book collection with live filtering:** in the "Books I've read" section, type in the search box to filter by title/author as you type, or click a category button (e.g. "Philosophy") to filter by type — both update instantly with no page reload.
- **Add a book:** in the "Add a book" form below the list, fill in title/author/language/type and click "Add book" — it appears in the list immediately and responds to the filter and to the Remove/Mark read buttons exactly like the books that were already there.
- **Remove / mark a book as read:** each book card has "Remove" and "Mark read" buttons — click either one to update that book, on any book in the list including ones you just added.
- **Contact form validation:** in the Contact section, try submitting the form empty or with an invalid email — each problem shows its own message next to the field, and the message disappears once you fix it; a valid submission shows a confirmation message.
- **Dark mode toggle:** the "Dark mode" button in the top-right of the header switches the whole page between light and dark themes.
